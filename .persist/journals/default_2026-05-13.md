## Discoveries

- macOS Tahoe (Darwin 25) tightened TCC around hdiutil disk image creation; even the user's interactive Terminal can't create mounts anymore. Permanent fix: ship as ZIP, not DMG.
- ditto -c -k --keepParent bakes xattrs as `._*` AppleDouble entries inside zip files. Tools other than `ditto -x -k` (Safari, Archive Utility, Sparkle's installer) extract those as real files inside the bundle, breaking codesign and triggering "could not verify it's not malware". Use /usr/bin/zip -X --symlinks --recurse-paths instead.
- Sparkle's sign_update reads the EdDSA private key from Keychain with an ACL that prompts on first access. Once the user clicks "Always Allow" in interactive Terminal, subsequent automated calls (even from Claude's bash shell) succeed.
- SCNView swallows mouseDown unless its hitTest is overridden to return nil — and `nonactivatingPanel` drops every "first click" on a non-key window unless the hit view returns true from acceptsFirstMouse. The two compound to make SwiftUI .onTapGesture completely non-functional in this configuration.
- @Published Combine publishers fire their cached current value to new subscribers. On cold launch this races with explicit imperative initialization and can silently interrupt running animations. Default to .dropFirst() for "react to changes" sinks.
- macOS App Sandbox + user-selected folder: NSOpenPanel grants ephemeral access; persistent access requires bookmarkData(options: .withSecurityScope) saved to UserDefaults, and startAccessingSecurityScopedResource() before each access.
- xAI Management API permissions are per-endpoint, not per-feature. "AddFileToCollection" is its own toggle separate from "CreateCollection" / "Collections: read/write". Both must be enabled.
